# M&D Transportes

Landing page institucional desenvolvida para a **M&D Transportes**, com foco em apresentar os serviços de guincho e transporte de veículos e facilitar o contato direto pelo WhatsApp.

O projeto foi pensado para atender usuários de São Bernardo do Campo e região, com navegação simples, carregamento rápido, layout responsivo e chamadas de ação voltadas para conversão.

## Objetivo do projeto

A M&D Transportes ainda não possuía um site próprio e tinha pouca presença nas buscas locais.

A proposta desta página é:

- apresentar os principais serviços;
- facilitar o contato pelo WhatsApp;
- melhorar a presença digital da empresa;
- oferecer uma experiência rápida em celulares;
- preparar a estrutura para SEO local;
- transmitir mais confiança durante a contratação do serviço.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript puro
- Google Fonts
- JSON-LD para dados estruturados
- SVG inline para ícones
- Imagens incorporadas no próprio arquivo HTML

Não foram utilizados frameworks, bibliotecas de interface ou ferramentas de build.

## Estrutura do site

A landing page possui as seguintes seções:

1. Cabeçalho com logo e botão de atendimento
2. Hero com chamada principal
3. Serviços oferecidos
4. Comentários demonstrativos
5. Apresentação da empresa
6. Localização e horário
7. Rodapé com contatos e redes sociais
8. Botão flutuante de WhatsApp

## Funcionalidades

- Layout responsivo para desktop, tablet e celular
- Compatibilidade com telas a partir de 360 px
- Botões de contato para dois números de WhatsApp
- Mensagem automática nos links do WhatsApp
- Atendimento informado como 24 horas
- Rolagem suave entre as seções
- Animações de entrada com IntersectionObserver
- Respeito à configuração `prefers-reduced-motion`
- Fallback para funcionamento sem JavaScript
- Links externos com `noopener noreferrer`
- Favicon incorporado no HTML
- Meta tags para SEO e compartilhamento
- Dados estruturados para mecanismos de busca
- Imagens com dimensões definidas para reduzir mudanças de layout

## Como executar o projeto

O projeto é composto por um único arquivo HTML.

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Dê dois cliques no arquivo `index.html`.

Também é possível abrir o projeto com a extensão Live Server no Visual Studio Code.

## Estrutura de arquivos

```text
md-transportes-site/
├── index.html
└── README.md
```

As imagens, o CSS e o JavaScript estão incorporados diretamente no `index.html`.

## Como publicar

O projeto pode ser publicado em serviços de hospedagem estática, como:

- GitHub Pages
- Vercel
- Netlify

### Exemplo com GitHub Pages

1. Crie um repositório no GitHub.
2. Envie o arquivo `index.html` e este `README.md`.
3. Acesse as configurações do repositório.
4. Abra a seção **Pages**.
5. Selecione a branch principal e a pasta raiz.
6. Salve e aguarde a criação do endereço público.

## Personalizações recomendadas antes da publicação

- confirmar o endereço exibido no site;
- substituir comentários demonstrativos por avaliações reais;
- inserir fotos reais da frota e dos serviços;
- revisar todos os textos com o responsável pela empresa;
- configurar o domínio definitivo;
- ativar as tags `canonical`, `og:url` e `og:image`;
- adicionar uma imagem própria para compartilhamento;
- testar todos os botões do WhatsApp;
- analisar o site no Lighthouse após a publicação.

## SEO e acessibilidade

O projeto inclui:

- HTML semântico;
- apenas um título principal `h1`;
- hierarquia organizada de títulos;
- textos alternativos nas imagens;
- foco visível para navegação pelo teclado;
- contraste de cores adequado;
- áreas clicáveis adaptadas para dispositivos móveis;
- meta description;
- Open Graph básico;
- dados estruturados no formato JSON-LD;
- `lang="pt-BR"`;
- `meta robots` configurada para indexação.

## Segurança

- Não existem senhas, tokens ou chaves de API no código.
- Todos os links externos abertos em nova guia possuem `rel="noopener noreferrer"`.
- O projeto não carrega scripts de terceiros.
- Não existe formulário com envio de dados.
- Os contatos são realizados diretamente pelo WhatsApp.
